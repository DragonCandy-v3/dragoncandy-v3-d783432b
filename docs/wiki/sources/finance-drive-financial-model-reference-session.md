# Finance Drive Financial Model Reference Session

The founder requested a library and repository reference to the seven-tab Finance
Drive XLSM after its calculation audit. The audit independently recalculated 1,367
formulas and passed twelve input-change scenarios; its scope was arithmetic and
dependencies, with commercial assumptions and unpriced costs left explicit.

The founder subsequently designated the workbook as one of DragonCandy’s financial
sources of truth. The library entry links to the live Drive file and distinguishes it
from the separate repo-generated investor model. The reference is stored in git and
published through the existing internal-only knowledge sync. It is readable in the
library; Donny search indexing is pending because the embedding provider exhausted
its API credits.
